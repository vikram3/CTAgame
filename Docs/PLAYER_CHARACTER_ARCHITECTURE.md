# Playable Characters

`CharacterController` remains the single platformer controller. CT and Alex select `CharacterData` resources for stats, projectile scene, and character-specific capability values. Alex is an inherited `player.tscn` scene, not a duplicated controller.

Alex's Phase 8 data defines boomerang-projectile selection and a three-hit shield capacity. The current repository has no Alex-specific visual or boomerang art assets; the inherited controller visual is tinted as a temporary placeholder only.
